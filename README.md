# C++/C 알고리즘 문제 풀이 저장소

이 저장소는 다양한 알고리즘 문제를 C와 C++로 해결한 코드를 모아둔 곳입니다. 문제들은 주로 백준 온라인 저지(Baekjoon Online Judge)에서 가져왔으며, `solved.ac` 클래스, 대학 강의, 프로그래밍 대회 준비 등 다양한 기준에 따라 정리되어 있습니다.

## 디렉토리 구조

이 프로젝트의 주요 디렉토리 설명은 다음과 같습니다:

- **`/class1-2`, `/class3`, `/class4`**:

  - 백준 온라인 저지 문제들의 풀이이며, `solved.ac` 클래스별로 분류되어 있습니다.

- **`/codingtest_cpp`**:

  - "코딩 테스트 합격자 되기 c++편" 책을 공부하며 작성한 코드입니다.

- **`/c_lecture`**:

  - 전북대학교 "C프로그래밍 특화교육(중급)" 강의에서 작성한 코드입니다.

- **`/algorithm_class`**:

  - 전북대학교 "알고리즘" 교과목의 과제 및 코드입니다.

- **`/APSS`**:

  - "알고리즘 문제 해결 전략" 책을 공부하며 작성한 코드입니다.

- **`/ucpc`**:

  - UCPC (대학생 프로그래밍 경진대회) 준비를 위해 푼 문제들입니다.

- **`/c`**:
  - 다양한 C 프로그래밍 과제에 대한 풀이를 포함합니다.
